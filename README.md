# Request For Comment (RFC)

This is repository is place for having structured feedback loops on various workstreams. It is a place to incubate ideas and turn them into specifications while maintaining history and context of what has and has not being considered. 

## Process

Create a pull request that adds a markdown document and ask peers to review it.

> ℹ️ You don't have to use code editor or github you to submit a proposal, you can use WYSIWYG tools like https://hackmd.io/ with github integration instead.
